# Kom-Auto — probni sajt

Vulkanizer i autoelektrika, Oblakovska 2f, Beograd.

## Objava na GitHub Pages

1. Napravi repozitorijum `kom-auto` na GitHub-u.
2. Prevuci `index.html` (i ovaj README) u repozitorijum → **Commit**.
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save.
4. Za minut-dva sajt je na: `https://m1ladino.github.io/kom-auto/`

`index.html` je samostalan fajl — sve slike, ikonice i kod su u njemu.
